# v0.5 Enterprise Knowledge Foundation

## Scope

Industrial AI Foundry is evolving from a process-safety application into a governed enterprise knowledge platform.

The platform domains are:

- Document Management
- Administration
- Engineering
- Process Safety
- Organization / Roles
- Enterprise Ontology
- Knowledge Graph
- Governed AI Agents

**Finance is intentionally not part of this release.**

## Workspace boundary

A Workspace is the primary governance boundary for enterprise data.

Examples:

- plant
- site
- project
- corporate administration
- process-safety program

Documents, administrative cases, approval tasks and role assignments belong to a Workspace.

Future RBAC/ABAC policies should evaluate:

- principal
- workspace
- role
- object classification
- action
- object attributes

## Document management

The document domain separates the logical document from individual versions.

```text
Document
  |
  +-- DocumentVersion 1
  +-- DocumentVersion 2
  +-- DocumentVersion 3
```

A Document can later be linked through the enterprise ontology to:

- Equipment
- P&ID
- PHA study
- AdministrativeCase
- ActionItem
- Project

Binary content will be stored in object storage. PostgreSQL remains the metadata system of record.

## Administration

AdministrativeCase is the common container for governed administrative processes.

Examples:

- change request
- permit / application
- controlled-document change
- internal approval
- formal review
- deadline-driven administrative task

ApprovalTask is modeled independently so that one object may require multiple approval gates.

## AI boundary

AI agents may:

- search documents
- summarize versions
- build context across ontology links
- propose classifications
- draft administrative responses
- draft PHA content

AI agents must not silently:

- approve a controlled document
- close an administrative case
- alter an approved PHA result
- grant an IPL credit
- bypass an approval task

State-changing actions will be mediated by governed action contracts and audit events.
