# v0.3 Industrial Intelligence

## Objective

v0.3 connects the semantic database to industrial engineering ingestion and a governed AI runtime.

## Added capabilities

### 1. DEXPI ingestion
The API accepts DEXPI/Proteus-style XML and creates:

- one `PIDDocument`
- multiple `DEXPINode` ontology objects
- provenance links back to the source document
- an audit event

The parser intentionally preserves raw XML attributes in object properties so mapping rules can evolve without losing source evidence.

### 2. Neo4j projection
PostgreSQL remains the governed system of record. The graph service projects ontology objects and links into Neo4j for traversal and graph-oriented retrieval.

This prevents the graph store from becoming an uncontrolled second source of truth.

### 3. PHA Copilot
The first PHA Copilot runtime is deliberately constrained.

It can:
- build ontology context
- inspect direct semantic relationships
- generate structured HAZOP review questions
- emit an audit event

It cannot:
- approve a hazard
- validate a safeguard
- grant IPL credit
- write an approved recommendation

Those operations remain future governed actions with human approval.

## Target pipeline

```text
DEXPI XML
   |
   v
DEXPI Importer
   |
   +--> PIDDocument
   +--> DEXPINode
   +--> provenance links
   |
   v
PostgreSQL Ontology
   |
   +--> Neo4j projection
   |
   v
PHA Context Builder
   |
   v
PHA Copilot Draft
   |
   v
Engineer Review
```
